۱. هفت عملگر ریاضی

عملگر علامتی است که روی یک یا دو مقدار کاری انجام می‌دهد. پایتون هفت عملگر ریاضی دارد. چهار مورد نخست همان‌هایی هستند که در مدرسه دیده‌اید و سه مورد بعدی کمی تازه‌اند.

# All the arithmetic operators of Python, applied to the same two numbers.
num1 = 24
num2 = 6

print('+  :', num1 + num2)    # addition        -> 30
print('-  :', num1 - num2)    # subtraction     -> 18
print('*  :', num1 * num2)    # multiplication  -> 144
print('/  :', num1 / num2)    # true division   -> 4.0  (always a float!)
print('// :', num1 // num2)   # floor division  -> 4    (whole part only)
print('%  :', num1 % num2)    # remainder       -> 0
print('** :', num1 ** num2)   # power           -> 24^6

عملگر / در پایتون همیشه نتیجه اعشاری می‌دهد، حتی وقتی تقسیم دقیق است. این تصمیم عمدی است: تقسیم در ریاضی معمولاً عدد اعشاری تولید می‌کند، پس پایتون رفتار یکسانی دارد و غافلگیرتان نمی‌کند.

۲. سه نوع تقسیم

سه عملگر / و // و % سه سؤال متفاوت را جواب می‌دهند. اگر ۱۰ شکلات داشته باشید و بخواهید بین ۳ نفر تقسیم کنید:

  • 10 / 3 می‌گوید سهم هر نفر چند شکلات است اگر بشود شکلات را بُرید: ۳٫۳۳
  • 10 // 3 می‌گوید هر نفر چند شکلات کامل می‌گیرد: ۳
  • 10 % 3 می‌گوید چند شکلات در جعبه باقی می‌ماند می‌ماند: ۱
# '/' always gives a float, even when the division is exact.
print(10 / 2)     # 5.0
print(10 / 3)     # 3.3333333333333335

# '//' throws away the decimal part and gives the whole number of times
# the second value fits into the first.
print(10 // 3)    # 3

# '%' gives what is left over. It is the tool we use to test even/odd numbers
# and to know whether one number divides another.
print(10 % 3)     # 1
print(10 % 2)     # 0  -> 10 is even
print(7 % 2)      # 1  -> 7 is odd

شرح مثال

  • خروجی 10 / 3 عدد عجیب 3.3333333333333335 است، با یک ۵ در انتها. این اشتباه پایتون نیست: کامپیوتر اعداد اعشاری را به شکل دودویی و با دقت محدود نگه می‌دارد، پس بعضی کسرها دقیق ذخیره نمی‌شوند. برای کارهای عادی مشکلی ندارد و در فصل شانزدهم با round مرتبش می‌کنیم.
  • // بخش اعشاری نتیجه را حذف می‌کند و آن را به نزدیک‌ترین عدد گرد نمی‌کند. برای مثال، 7 // 2 برابر ۳ است، نه ۴.
  • وقتی هر دو طرف // عدد صحیح باشند، نتیجه صحیح است. اگر یک طرف اعشاری باشد، نتیجه اعشاری می‌شود: 7.0 // 2 برابر 3.0 است.

۳. باقیمانده به چه دردی می‌خورد

عملگر % در نگاه اول بی‌مصرف به نظر می‌رسد، ولی یکی از پرکاربردترین عملگرهای برنامه‌نویسی است. سه کاربرد اصلی‌اش:

  • زوج یا فرد بودن. اگر n % 2 برابر صفر باشد عدد زوج است، وگرنه فرد. در فصل چهارم دقیقاً همین را می‌نویسیم.
  • بخش‌پذیری. اگر n % 5 صفر باشد یعنی n بر ۵ بخش‌پذیر است. در فصل هشتم با همین ایده عدد اول پیدا می‌کنیم.
  • جدا کردن ارقام. n % 10 رقم یکان یک عدد را می‌دهد و n // 10 بقیه عدد را. با تکرار این دو، هر عدد را می‌شود رقم به رقم باز کرد.

۴. اولویت عملگرها

وقتی چند عملگر در یک عبارت باشند، پایتون همان ترتیبی را رعایت می‌کند که در ریاضی یاد گرفته‌اید: اول توان، بعد ضرب و تقسیم، آخر جمع و تفریق. عملگرهای هم‌رتبه از چپ به راست حساب می‌شوند. 

# Python follows the usual mathematical order of operations:
#   1) **        2) * / // %        3) + -
# Operators on the same level are evaluated from left to right.

print(2 + 3 * 4)        # 14, not 20: multiplication happens first
print((2 + 3) * 4)      # 20: parentheses change the order
print(2 ** 3 ** 2)      # 512: ** is evaluated from RIGHT to left -> 2 ** 9
print(-3 ** 2)          # -9: the power is applied before the minus sign
print((-3) ** 2)        # 9

# When in doubt, add parentheses: they cost nothing and make the code readable.

شرح مثال

  • 2 + 3 * 4 برابر ۱۴ است، نه ۲۰. ضرب زودتر انجام می‌شود.
  • پرانتز همیشه برنده است. (2 + 3) * 4 برابر ۲۰ است.
  • عملگر توان یک استثناست: از راست به چپ حساب می‌شود. پس 2 ** 3 ** 2 یعنی 2 ** 9 که ۵۱۲ است، نه 8 ** 2 که ۶۴ می‌شد.
  • -3 ** 2 برابر منفی ۹ است، چون اول ۳ به توان ۲ می‌رسد و بعد منفی می‌شود. اگر منفی سه را به توان دو می‌خواهید، باید پرانتز بگذارید.
قانون طلایی

ضرورتی ندارد جدول اولویت را حفظ کنید. برنامه‌نویس‌های حرفه‌ای هم حفظ نیستند. هر جا شک کردید، پرانتز بگذارید. پرانتز اضافه هیچ هزینه‌ای ندارد و کد را برای کسی که بعداً می‌خواندش روشن‌تر می‌کند.

۵. به‌روزرسانی یک متغیر با خودش

این خط در نگاه اول ممکن است عجیب به نظر برسد: num1 = num1 + num2. اگر آن را مانند یک معادله ریاضی بخوانید، بی‌معنا به نظر می‌رسد؛ اما اینجا علامت مساوی، عملگر انتساب است. پایتون ابتدا عبارت سمت راست را محاسبه می‌کند و سپس نتیجه را در متغیر سمت چپ قرار می‌دهد.

# A variable can be updated using its own current value.
# The right-hand side is calculated first, then stored back into the name.
num1 = 24
num2 = 6

num1 = num1 + num2   # 24 + 6 = 30
print(num1)

num1 = num1 - num2   # 30 - 6 = 24
print(num1)

number = 3
result = number + 1
print(result)        # 4

۶. انتساب ترکیبی

چون نوشتن num1 = num1 + num2 آن‌قدر رایج است، پایتون شکل کوتاه‌تری برایش دارد. 

# 'num1 = num1 + num2' is so common that Python offers a shorter form: '+='.
num1 = 24
num2 = 6

num1 += num2   # same as num1 = num1 + num2
print(num1)    # 30

num1 -= num2   # same as num1 = num1 - num2
print(num1)    # 24

num1 *= num2   # same as num1 = num1 * num2
print(num1)    # 144

num1 /= num2   # same as num1 = num1 / num2  -> the result becomes a float
print(num1)    # 24.0

# The same short form exists for // , % and **
num1 //= 5
print(num1)    # 4.0

شرح مثال

  • هر هفت عملگر ریاضی شکل ترکیبی دارند: += و -= و *= و /= و //= و %= و **=.
  • به خط چهارم دقت کنید: بعد از /= مقدار 24.0 شده است، با اعشار. چون عملگر تقسیم همیشه اعشاری برمی‌گرداند، نوع متغیر از این به بعد float است. به همین دلیل خط آخر هم 4.0 چاپ می‌کند و نه 4.
  • ترتیب دو علامت مهم است: += درست است، =+ غلط است. x =+ 5 خطا نمی‌دهد ولی معنایش «x را مساوی مثبت ۵ قرار بده» است و یک اشتباه بی‌سروصداست.

۷. چند برنامه کوچک

# Read a number from the user and increase it by 2.
user_input = input('Enter a number: ')

number = int(user_input)   # input() gives text, so we must convert it

پرانتزی که حذف آن می‌تواند نتیجه را کاملاً تغییر دهد

اگر بنویسید a + b + c / 3، به خاطر اولویت عملگرها فقط c بر سه تقسیم می‌شود و جواب کاملاً غلط در می‌آید. بدتر اینکه برنامه هیچ خطایی نمی‌دهد و شما تا وقتی جواب را با ماشین‌حساب چک نکنید، متوجه نمی‌شوید. این موارد را خطای منطقی می‌گویند و سخت‌ترین نوع خطا هستند.

۸. ثانیه به ساعت و دقیقه

این مثال کلاسیک‌ترین کاربرد // و % در کنار هم است و ارزش دارد که خط به خط دنبالش کنید. 

# A classic use of // and % together:
# convert a number of seconds into hours, minutes and seconds.
user_input = input('Enter a number of seconds: ')
total_seconds = int(user_input)

hours = total_seconds // 3600            # how many whole hours
remaining = total_seconds % 3600         # what is left after removing the hours
minutes = remaining // 60                # how many whole minutes
seconds = remaining % 60                 # what is left after removing the minutes

print(hours, 'h', minutes, 'm', seconds, 's')

تبدیل ثانیه به زمان: نمونه 10_seconds_to_time.py

Enter a number of seconds: 3725
1 h 2 m 5 s

شرح مثال

عدد ۳۷۲۵ را دنبال کنیم:

  • هر ساعت ۳۶۰۰ ثانیه است. 3725 // 3600 برابر ۱ است، پس یک ساعت کامل داریم.
  • 3725 % 3600 برابر ۱۲۵ است. یعنی بعد از برداشتن آن یک ساعت، ۱۲۵ ثانیه باقی مانده.
  • 125 // 60 برابر ۲ است، پس دو دقیقه کامل داریم.
  • 125 % 60 برابر ۵ است، یعنی ۵ ثانیه ته‌مانده.

الگویی که اینجا دیدید در همه تبدیل واحدها تکرار می‌شود: با // واحد بزرگ‌تر را بردار، با % باقیمانده را نگه دار، و روی باقیمانده همین کار را با واحد کوچک‌تر تکرار کن.

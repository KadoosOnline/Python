۱. برنامه چیست

کامپیوتر دستگاهی است که دستورهایی را که به آن داده می‌شود اجرا می‌کند. خودش هدف یا تصمیم مستقلی ندارد و بر اساس دستورهای برنامه عمل می‌کند. برنامه مجموعه‌ای از دستورهاست که برای انجام یک کار مشخص، به ترتیبی معین نوشته می‌شوند.

کامپیوتر دستورهای برنامه را در نهایت در سطحی بسیار پایین و به شکل الگوهای دودویی اجرا می‌کند. نوشتن مستقیم چنین دستورهایی برای انسان دشوار است، به همین دلیل زبان‌های برنامه‌نویسی به وجود آمده‌اند. ما با زبانی می‌نویسیم که برای انسان قابل فهم‌تر است و سپس ابزارهای نرم‌افزاری آن را به شکلی تبدیل می‌کنند که ماشین بتواند اجرا کند. پایتون یکی از همین زبان‌های برنامه‌نویسی است.

یک مقایسه ساده: دستور پخت غذا هم یک برنامه است. مواد لازم همان داده است، مراحل پخت همان دستورها هستند، و «اگر آب جوش آمد، برنج را بریزید» همان شرط است که در فصل چهارم می‌بینید. هر چیزی که در این کتاب یاد می‌گیرید، در نهایت یکی از این سه چیز است: داده، دستور، یا تصمیم درباره اینکه کدام دستور اجرا شود.

یک نکته درباره یادگیری

برنامه‌نویسی بیشتر شبیه شنا کردن است تا حفظ کردن مطالب تئوری. همان‌طور که با خواندن درباره شنا، شناگر نمی‌شویم، با خواندن کد هم برنامه‌نویس نمی‌شویم. هر مثالی را که در این کتاب می‌بینید، خودتان تایپ و اجرا کنید. حتی بهتر است بعد از اجرا، بخش کوچکی از آن را تغییر دهید و دوباره اجرا کنید؛ این کار کمک می‌کند جزئیات کد را واقعاً یاد بگیرید.

۲. چرا پایتون

زبان‌های برنامه‌نویسی زیادی وجود دارند. دلیل اینکه این دوره با پایتون شروع می‌شود، این چند مورد است:

  • خواناست. کد پایتون به جمله انگلیسی نزدیک است. برنامه‌ای که در زبان‌های دیگر بیست خط طول می‌کشد، در پایتون معمولاً پنج خط است.
  • برای شروع ساده است، اما زبان محدودی نیست. همان زبانی که امروز با آن نخستین دستورهای خود را می‌نویسید، در پروژه‌های علمی، خدمات وب، تحلیل داده و هوش مصنوعی نیز استفاده می‌شود.
  • همه‌کاره است. با پایتون می‌شود سایت ساخت، برنامه دسکتاپ ساخت، داده تحلیل کرد، ربات تلگرام نوشت، کارهای تکراری ویندوز را خودکار کرد و مدل هوش مصنوعی آموزش داد.
  • کتابخانه‌های فراوانی دارد. برای بسیاری از کارهای متداول، کتابخانه‌هایی آماده وجود دارد که توسعه برنامه را بسیار سریع‌تر و ساده‌تر می‌کنند.
  • رایگان است و روی ویندوز و لینوکس و مک کار می‌کند.

۳. نصب پایتون

ویندوز

  1. به نشانی python.org بروید و از بخش Downloads آخرین نسخه پایتون ۳ را دانلود کنید.
  2. فایل نصب را اجرا کنید.
  3. در همان صفحه اول، پیش از هر کاری، تیک گزینه Add python.exe to PATH را بزنید.
  4. روی Install Now بزنید و منتظر بمانید تا تمام شود.
مهم‌ترین تیک نصب

اگر تیک Add python.exe to PATH را نزنید، پایتون نصب می‌شود ولی ویندوز نمی‌داند کجاست، و هر بار که در ترمینال بنویسید python پیام می‌گیرید که چنین دستوری وجود ندارد. اگر این اتفاق افتاد، ضرورتی ندارد ناراحت شوید: فایل نصب را دوباره اجرا کنید، گزینه Modify را بزنید و مسیر را اضافه کنید، یا کل پایتون را حذف و دوباره با تیک درست نصب کنید.

لینوکس

در بیشتر توزیع‌ها پایتون از قبل نصب است. اگر نبود: 

sudo apt update
sudo apt install python3 python3-pip

نصب پایتون در اوبونتو و دبیان

مک

نسخه‌ای که همراه سیستم‌عامل می‌آید قدیمی است. بهتر است نصب‌کننده رسمی را از python.org بگیرید یا از brew install python استفاده کنید.

۴. مطمئن شویم نصب درست انجام شده

ترمینال را باز کنید. در ویندوز کلیدهای Win + R را بزنید، بنویسید cmd و اینتر بزنید. حالا این دستور را بنویسید: 

python --version

نمایش نسخه نصب‌شده. در لینوکس و مک به جای python بنویسید python3

باید چیزی شبیه این ببینید:

Python 3.12.4

اگر شماره نسخه را دیدید، کار تمام است. هر نسخه‌ای که با ۳ شروع شود و از ۳.۱۰ بالاتر باشد برای این کتاب مناسب است.

۵. نصب VS Code

برنامه پایتون یک فایل متنی ساده است با پسوند py. و در تئوری با Notepad هم می‌شود نوشتش. اما یک ویرایشگر کد کار را بسیار راحت‌تر می‌کند: رنگ‌آمیزی کد، تکمیل خودکار، نشان دادن خطا پیش از اجرا و یک ترمینال داخلی.

  1. از نشانی code.visualstudio.com برنامه را دانلود و نصب کنید.
  2. VS Code را باز کنید.
  3. از نوار کنار چپ، آیکون Extensions را بزنید.
  4. بنویسید Python و افزونه رسمی مایکروسافت را نصب کنید.
یک تنظیم که همان اول انجام دهید

از منوی File گزینه Auto Save را روشن کنید. بارها پیش می‌آید که برنامه‌نویس تازه‌کار کد را عوض می‌کند، اجرا می‌کند و می‌بیند هیچ تغییری نکرده است، فقط به این دلیل که فایل ذخیره نشده بود.

۶. اولین برنامه

یک پوشه به نام python-course جایی روی کامپیوترتان بسازید و آن پوشه را با VS Code باز کنید: منوی File، گزینه Open Folder. حالا یک فایل تازه بسازید به نام hello.py و این یک خط را داخلش بنویسید: 

print("Hello, Kadoos!")

اولین برنامه: فایل hello.py

سه راه برای اجرا کردنش دارید:

  1. دکمه مثلثی شکل بالا سمت راست پنجره VS Code را بزنید.
  2. یا کلید F5 را بزنید و گزینه Python File را انتخاب کنید.
  3. یا در ترمینال، در همان پوشه‌ای که فایل هست، بنویسید: 
python hello.py

اجرای فایل از ترمینال

خروجی:

Hello, Kadoos!

همین؛ شما نخستین برنامه‌تان را اجرا کردید. ادامه این کتاب، گسترش همین ایده است: به جای یک متن ثابت، ورودی کاربر را می‌گیریم؛ به جای یک بار اجرا، اجرای تکرارشونده را یاد می‌گیریم؛ و به جای نمایش ساده روی صفحه، داده‌ها را در فایل و پایگاه داده ذخیره می‌کنیم.

۷. حالت تعاملی

گاهی نمی‌خواهید فایل بسازید و فقط می‌خواهید یک موضوع کوچک را امتحان کنید. در ترمینال بنویسید python و اینتر بزنید. علامت >>> ظاهر می‌شود. اینجا هر چه بنویسید بلافاصله اجرا می‌شود:

>>> 2 + 3
5
>>> print("salam")
salam
>>> 10 / 4
2.5

برای بیرون آمدن، بنویسید exit() و اینتر بزنید. به این حالت مفسر تعاملی یا REPL می‌گویند و در تمام طول این دوره، بهترین جا برای امتحان کردن یک ایده کوچک است.

۸. پیام خطا دشمن شما نیست

وقتی اجرای برنامه با مشکل مواجه شود، پایتون پیام خطا نمایش می‌دهد. بسیاری از تازه‌کارها با دیدن این پیام تصور می‌کنند برنامه صرفاً «خطا داده است»، در حالی که پیام خطا در واقع راهنمای حل مسئله است و معمولاً مشخص می‌کند مشکل در کجا و از چه نوعی است. سه خطای رایجی که در شروع کار با آنها روبه‌رو می‌شوید اینها هستند:

  File "hello.py", line 1
    print("Hello)
          ^
SyntaxError: unterminated string literal

یعنی خطای نگارشی: گیومه بسته نشده است. شماره خط را می‌دهد و با علامت ^ جای دقیق مشکل را نشان می‌دهد. 

NameError: name 'nmae' is not defined

یعنی اسمی به کار برده‌اید که پایتون نمی‌شناسد. تقریباً همیشه غلط تایپی است: nmae به جای name. 

IndentationError: expected an indented block

یعنی تورفتگی فراموش شده است. در فصل چهارم می‌بینید که در پایتون فاصله ابتدای خط معنا دارد.

قانون خواندن پیام خطا

پیام خطا را از آخر بخوانید. معمولاً خط آخر نوع خطا و علت کلی آن را مشخص می‌کند و خطوط بالاتر، مسیر رسیدن برنامه به آن خط را نشان می‌دهند. اگر معنی خط آخر را متوجه نشدید، می‌توانید متن انگلیسی آن را جست‌وجو کنید. جست‌وجوی پیام خطا یکی از روش‌های معمول عیب‌یابی برای برنامه‌نویسان است.

۹. چند قانون که از در همین مرحله باید بدانید

  • پایتون به حروف بزرگ و کوچک حساس است. print کار می‌کند ولی Print خطا ایجاد می‌کند.
  • تورفتگی معنا دارد. در بیشتر زبان‌ها فاصله ابتدای خط فقط برای زیبایی است. در پایتون بخشی از دستور زبان است. استاندارد: چهار فاصله.
  • نام فایل‌هایتان را انگلیسی و بدون فاصله بگذارید. my_program.py خوب است، برنامه من.py دردسر درست می‌کند.
  • هرگز نام فایلتان را برابر نام یک ماژول پایتون نگذارید. فایلی به نام random.py یا math.py باعث می‌شود برنامه‌های بعدی‌تان به شکل عجیبی خراب شوند.
  • پایتون ۲ دیگر نسخه مورد استفاده برای توسعه جدید نیست. اگر در اینترنت کدی دیدید که print "hello" را بدون پرانتز نوشته است، احتمالاً مربوط به پایتون ۲ است و با ساختار پایتون ۳ سازگار نیست.

۱۰. نقشه راه چهل جلسه

بهتر است از همین ابتدا بدانید در این کتاب چه مسیری را طی می‌کنید. مسیر یادگیری این کتاب پنج مرحله دارد:

پلهفصل‌هاچه چیزی یاد می‌گیرید
پایه‌ها۱ تا ۱۰متغیر، شرط، حلقه و لیست. یعنی هر چیزی که برای نوشتن یک الگوریتم لازم است.
ساختاردهی۱۱ تا ۲۰تابع، ساختمان داده، ماژول، فایل و خطا. یعنی نوشتن برنامه‌ای که بزرگ‌تر از یک صفحه است.
شیءگرایی۲۱ تا ۲۶مدل کردن دنیای واقعی با کلاس، به‌علاوه سبک نوشتن کد پایتونی.
داده و ابزار۲۷ تا ۳۳فایل‌های داده‌ای، اینترنت، پایگاه داده و الگوهای طراحی.
برنامه واقعی۳۴ تا ۴۰رابط گرافیکی، فایل اجرایی، همروندی، وب و پروژه پایانی.

تمرین‌های فصل صفر

  1. پایتون را نصب کنید و شماره نسخه‌اش را در ترمینال ببینید.
  2. VS Code و افزونه Python را نصب کنید.
  3. پوشه python-course را بسازید و فایل hello.py را داخلش اجرا کنید.
  4. در حالت تعاملی، حاصل 7 * 8 و 2 ** 10 را ببینید.
  5. عمداً یک گیومه را باز بگذارید و اجرا کنید. پیام خطا را بخوانید و ببینید شماره خط را درست گفته است یا نه.
  6. یک برنامه بنویسید که سه خط چاپ کند: نام شما، نام شهرتان و نام دوره.

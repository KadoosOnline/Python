حلقه while

حلقه for وقتی خوب است که از قبل بدانید چند بار باید تکرار کنید. ولی خیلی وقت‌ها نمی‌دانید: تا وقتی کاربر خسته شود، تا وقتی جواب درست پیدا شود، تا وقتی فایل تمام شود. اینجا جای while است.

۱. اولین while

while یعنی «تا وقتی که». شرطی می‌گیرد و تا وقتی آن شرط درست است، بدنه‌اش را تکرار می‌کند. 

# A 'while' repeats as long as its condition is True.
# Something inside the loop MUST eventually make the condition False,
# otherwise the program never stops (an "infinite loop").
x = 0

while x < 10:
    x += 1          # without this line the loop would never end
    print(x)

شرح مثال

  • سه چیز همیشه لازم است: مقدار اولیه پیش از حلقه، شرط در خط while، و تغییر داخل بدنه.
  • اگر خط x += 1 نبود، شرط همیشه درست می‌ماند و برنامه هرگز تمام نمی‌شد.
  • شرط پیش از هر دور بررسی می‌شود. اگر از همان اول نادرست باشد، بدنه حتی یک بار هم اجرا نمی‌شود.

۲. حلقه بی‌پایان

اگر برنامه گیر کرد

حلقه بی‌پایان یعنی حلقه‌ای که شرطش هرگز نادرست نمی‌شود. برنامه ظاهراً هنگ می‌کند یا بی‌نهایت خط چاپ می‌کند. برای متوقف کردنش در ترمینال کلیدهای Ctrl + C را بزنید. این کلید را در همین مرحله یاد بگیرید، چون در هفته اول کار با while چند بار لازمتان می‌شود.

سه علت رایج حلقه بی‌پایان:

  • یادتان رفته متغیر شرط را داخل حلقه تغییر دهید.
  • خط تغییردهنده را اشتباهاً بیرون حلقه گذاشته‌اید، یعنی تورفتگی‌اش غلط است.
  • شرط را برعکس نوشته‌اید، مثلاً x > 0 در حالی که x دارد بزرگ‌تر می‌شود.

۳. for یا while، کدام

# Use 'for' when you know in advance how many turns you need.
for i in range(1, 6):
    print(i, end=' ')
print()

# Use 'while' when the number of turns depends on something that happens
# during the loop.
i = 1
while i <= 5:
    print(i, end=' ')
    i += 1
print()

۴. while True و break

الگویی که در برنامه‌های واقعی بیش از همه دیده می‌شود این است: حلقه را عمداً بی‌پایان می‌سازیم و با break از وسطش بیرون می‌پریم. مقداری که باعث خروج می‌شود را نگهبان می‌نامند. 

# A "sentinel" is a special value that means "stop".
# Here the sentinel is the word 'exit'.
total = 0

while True:                              # loop for ever ...
    user_input = input('Enter a number (or "exit"): ')

    if user_input == 'exit':
        break                            # ... until break jumps out of it

    number = float(user_input)
    total += number
    print('Sum is:', total)

print('Final sum:', total)

شرح مثال

  • while True یعنی شرط همیشه درست است، پس حلقه به خودی خود تمام نمی‌شود.
  • break بلافاصله از حلقه بیرون می‌پرد و اجرا از اولین خط بعد از حلقه ادامه می‌یابد.
  • بررسی نگهبان باید پیش از تبدیل نوع باشد. اگر اول float(user_input) را بنویسید، کلمه exit برنامه را خراب می‌کند.
  • چرا این الگو بهتر از گذاشتن شرط در خود while است؟ چون باید ورودی را بگیریم تا بتوانیم بررسی‌اش کنیم، و گرفتن ورودی وسط حلقه اتفاق می‌افتد، نه پیش از آن.

۵. دستور continue

break از حلقه بیرون می‌پرد، ولی continue فقط سایر موارد نیزین دور را رد می‌کند و به بالای حلقه برمی‌گردد.

# 'continue' skips the REST of the current turn and goes back to the top.
# Here the odd numbers are simply ignored.
total = 0

while True:
    user_input = input('Enter a number (or "exit"): ')

    if user_input == 'exit':
        break

    number = int(user_input)

    if number % 2 != 0:
        print('Odd number ignored.')
        continue                 # go back to the input() line

    total += number
    print('Sum is:', total)

۶. میانگین در حال اجرا

# Two accumulators: the total and how many numbers were entered.
total = 0
counter = 0

while True:
    user_input = input('Enter a number (or "exit"): ')

    if user_input == 'exit':
        break

    number = float(user_input)

    total += number
    counter += 1

    print('Average is:', total / counter)

# After the loop, counter may still be 0 - never divide by it blindly.
if counter == 0:
    print('No number was entered.')
else:
    print('Final average:', total / counter)

داخل حلقه، تقسیم بر counter بی‌خطر است چون همان بالا یکی اضافه شده و حتماً بزرگ‌تر از صفر است. ولی بعد از حلقه چنین تضمینی نداریم: اگر کاربر همان اول exit بزند، شمارنده صفر می‌ماند. برای همین شرط پایانی لازم است.

۷. اعتبارسنجی ورودی

این کاربردی‌ترین الگوی این فصل است. تا وقتی کاربر جواب معتبر ندهد، سؤال را تکرار می‌کنیم. 

# A very common use of 'while': keep asking until the answer makes sense.
while True:
    user_input = input('Enter your age (1-120): ')

    if not user_input.isdigit():
        print('Please type digits only.')
        continue

    age = int(user_input)

    if age < 1 or age > 120:
        print('The age must be between 1 and 120.')
        continue

    break        # the value is valid, leave the loop

print('Your age is', age)

شرح مثال

  • ساختار: هر بررسی که رد شود، پیام می‌دهد و continue می‌کند. اگر همه بررسی‌ها رد شدند، به break می‌رسیم.
  • isdigit() از فصل سوم اینجا حیاتی است: پیش از int() مطمئن می‌شویم ورودی واقعاً رقم است. بدون آن، تایپ یک حرف برنامه را خراب می‌کند.
  • ترتیب مهم است: اول بررسی نوع، بعد تبدیل، بعد بررسی بازه.
  • در فصل نوزدهم راه دیگری برای همین کار می‌بینید که try نام دارد و برای حالت‌های پیچیده‌تر مناسب‌تر است.

۸. بازی حدس عدد

# A tiny game: the program knows a number, the player has to find it.
SECRET = 16

tries = 0

while True:
    user_input = input('Enter a number: ')
    guess = int(user_input)
    tries += 1

    if guess < SECRET:
        print('The number is greater!')
    elif guess > SECRET:
        print('The number is smaller!')
    else:
        print(f'You win! You needed {tries} tries.')
        break

۹. تشخیص عدد اول

# A prime number is only divisible by 1 and by itself.
# As soon as we find one divisor we can stop looking -> 'break'.
user_input = input('Enter your number: ')
number = int(user_input)

# 0, 1 and the negative numbers are NOT prime, so we handle them separately.
if number < 2:
    is_prime = False
else:
    is_prime = True
    for i in range(2, number):
        if number % i == 0:
            is_prime = False
            break            # no need to test the remaining divisors

if is_prime:
    print("It's prime!")
else:
    print("It's not prime.")

شرح مثال

  • الگوی مهمی اینجا هست: یک متغیر پرچم به نام is_prime که با True شروع می‌شود و به محض پیدا شدن مقسوم‌علیه، False می‌شود.
  • break بعد از پیدا شدن اولین مقسوم‌علیه، بقیه حلقه را بی‌فایده می‌داند و بیرون می‌پرد. برای عدد یک میلیون این یعنی صرفه‌جویی عظیم.
  • break در حلقه for هم درست مثل while کار می‌کند.
باگی که در نسخه اصلی بود

نسخه اصلی این برنامه شرط number < 2 را نداشت. نتیجه این بود که عدد ۱ و عدد صفر و حتی اعداد منفی «اول» اعلام می‌شدند، چون حلقه range(2, 1) اصلاً اجرا نمی‌شد و پرچم True باقی می‌ماند. درس: همیشه حالت‌های مرزی را جدا بررسی کنید. حلقه‌ای که هیچ دوری نمی‌زند، خطر پنهان دارد.

۱۰. بلوک else حلقه

این یکی از ویژگی‌های عجیب و کم‌شناخته پایتون است: حلقه می‌تواند else داشته باشد. آن بلوک وقتی اجرا می‌شود که حلقه به طور طبیعی تمام شود، یعنی با break قطع نشده باشد. 

# A loop may have an 'else' block. It runs only when the loop finished
# normally, that is when it was NOT stopped by a 'break'.
number = int(input('Enter a number: '))

for i in range(2, number):
    if number % i == 0:
        print(f'{number} is divisible by {i}')
        break
else:
    # reached only when no divisor was found
    print(f'{number} is prime!')

else حلقه: نمونه 09_while_else.py

مقایسه کنید با نسخه قبلی: اینجا دیگر متغیر پرچم ضرورتی ندارد. اگر حلقه مقسوم‌علیهی پیدا کند، break می‌زند و else اجرا نمی‌شود. اگر تا آخر برود و چیزی پیدا نکند، else اجرا می‌شود.

اسمش گمراه‌کننده است

بهتر بود اسمش nobreak بود، نه else. چون معنایش «اگر حلقه شکسته نشد» است، نه «در غیر این صورت». طراح پایتون هم بعدها گفته که این نام‌گذاری اشتباه بوده است. با این حال، الگوی «جست‌وجو کن و اگر پیدا نشد کاری بکن» را واقعاً تمیز می‌نویسد.

۱۱. باز کردن یک عدد رقم به رقم

# Taking a number apart digit by digit is a classic 'while' exercise.
user_input = input('Enter a positive number: ')
number = int(user_input)

digit_count = 0
digit_sum = 0

while number > 0:
    digit = number % 10       # the last digit
    digit_sum += digit
    digit_count += 1
    number = number // 10     # remove the last digit

print('Number of digits:', digit_count)
print('Sum of the digits:', digit_sum)

تمرین‌های فصل هشت

  1. تا وقتی کاربر exit نزده عدد بگیرید و در پایان بزرگ‌ترین را چاپ کنید.
  2. یک پرسش رمز بنویسید که به کاربر سه فرصت بدهد.
  3. عدد بگیرید تا exit، و بگویید چند تا مثبت و چند تا منفی بودند.
  4. یک عدد بگیرید و برعکسش کنید، مثلاً 123 به 321، فقط با // و %.
  5. بازی حدس عدد را طوری بنویسید که کامپیوتر عدد را تصادفی انتخاب کند. کافی است import random کنید؛ در فصل شانزدهم کاملش را می‌بینید.
  6. یک عدد بگیرید و همه مقسوم‌علیه‌هایش را چاپ کنید.
  7. دو عدد بگیرید و بزرگ‌ترین مقسوم‌علیه مشترکشان را با یک حلقه while پیدا کنید.
  8. منوی فصل پنجم را داخل یک حلقه بگذارید تا تا وقتی کاربر گزینه صفر را نزده تکرار شود.

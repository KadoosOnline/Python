حلقه‌های تودرتو و الگوها

وقتی یک حلقه داخل حلقه دیگر می‌گذارید، از خط به صفحه می‌رسید. این فصل تمرین محض است: کشیدن شکل با ستاره، که ساده به نظر می‌رسد ولی بهترین راه برای اینکه حلقه واقعاً در ذهنتان جا بیفتد.

۱. حلقه داخل حلقه

قانون طلایی این فصل یک جمله است: حلقه داخلی برای هر یک دور حلقه بیرونی، از اول تا آخر کامل اجرا می‌شود. 

# The inner loop runs from start to end for EVERY single turn of the outer loop.
# 3 outer turns x 4 inner turns = 12 lines.
for i in range(3):
    for j in range(4):
        print(f'i={i}, j={j}')
    print('--- end of one outer turn ---')

شرح مثال

  • حلقه بیرونی سه بار می‌چرخد، حلقه داخلی چهار بار. مجموع اجرای بدنه داخلی: سه ضربدر چهار، یعنی دوازده بار.
  • متغیر i کند حرکت می‌کند و j تند. برای هر مقدار i، تمام مقدارهای j طی می‌شوند.
  • خط آخر داخل حلقه بیرونی است ولی بیرون حلقه داخلی، پس فقط سه بار اجرا می‌شود. تورفتگی است که این را مشخص می‌کند.
مقایسه‌ای که کار را آسان می‌کند

به عقربه‌های ساعت فکر کنید. عقربه ساعت‌شمار حلقه بیرونی است و دقیقه‌شمار حلقه داخلی. برای هر یک ساعت، دقیقه‌شمار یک دور کامل ۶۰ تایی می‌زند.

۲. مستطیل ستاره

از اینجا به بعد یک الگوی ثابت داریم: حلقه بیرونی سطرها را می‌شمارد و حلقه داخلی ستون‌ها را. کلید کار، دو تا print است. 

# A rectangle of stars: the outer loop counts the rows,
# the inner loop prints the characters of one row.
ROWS = 4
COLUMNS = 8

for row in range(ROWS):
    for column in range(COLUMNS):
        # end='' keeps the cursor on the same line
        print('*', end=' ')
    # this print() ends the current line and starts a new one
    print()

شرح مثال

  • print('*', end=' ') ستاره را چاپ می‌کند و روی همان خط می‌ماند. بدون end، هر ستاره یک خط جدا می‌گرفت.
  • print() خالی بعد از حلقه داخلی، سطر را می‌بندد. این خط حتماً باید بیرون حلقه داخلی و داخل حلقه بیرونی باشد.
  • اگر شکل شما به هم ریخت، اولین چیزی که باید چک کنید تورفتگی همین print() خالی است.

۳. جدول ضرب

# The multiplication table of the numbers 1..n
user_input = input('Enter a number: ')
n = int(user_input)

for i in range(1, n + 1):
    for j in range(1, n + 1):
        print(i * j, end='\t')   # \t keeps the columns aligned
    print()

۴. مثلث رشدیابنده

برای مثلث، تعداد ستاره‌های هر سطر باید متفاوت باشد. یعنی حلقه داخلی نباید عدد ثابت داشته باشد، بلکه باید به i وابسته باشد. 

# Row 0 gets 0 stars, row 1 gets 1 star, row 2 gets 2 stars ...
# Version 1: the inner loop simply runs 'i' times. This is the clean way.
for i in range(5):
    for j in range(i):
        print('*', end=' ')
    print()

print('---')

# Version 2: the inner loop always runs 5 times but only prints when i > j.
# It gives the same drawing; it just does more useless turns.
for i in range(5):
    for j in range(5):
        if i > j:
            print('*', end=' ')
    print()

شرح مثال

  • روش اول: range(i) یعنی حلقه داخلی به اندازه شماره سطر می‌چرخد. سطر صفر هیچ ستاره‌ای ندارد، سطر یک، یک ستاره و همین‌طور تا آخر.
  • روش دوم: حلقه داخلی همیشه پنج بار می‌چرخد ولی فقط وقتی i > j باشد چیزی چاپ می‌کند. نتیجه یکی است ولی نصف دورها بی‌فایده‌اند.
  • هر دو نسخه در فایل نمونه آمده‌اند تا مقایسه کنید. در برنامه واقعی روش اول را انتخاب کنید: هم سریع‌تر است و هم قصد نویسنده را روشن‌تر بیان می‌کند.

۵. مثلث نزولی

# A triangle that shrinks: 5 stars, then 4, then 3 ...
SIZE = 5

for i in range(SIZE, 0, -1):
    for j in range(i):
        print('*', end=' ')
    print()

print('---')

# The same shape written with a condition instead of a counting-down range.
for i in range(SIZE):
    for j in range(SIZE):
        if i <= j:
            print('*', end=' ')
    print()

۶. مثلث راست‌چین

برای اینکه ستاره‌ها به سمت راست هل داده شوند، باید پیش از آنها فاصله چاپ کنیم. فاصله هم یک کاراکتر است و جا اشغال می‌کند. 

# To push the stars to the right we print SPACES first.
# Row i gets (SIZE - 1 - i) spaces and (i + 1) stars.
SIZE = 5

for i in range(SIZE):
    for j in range(SIZE):
        if j < SIZE - 1 - i:
            print(' ', end=' ')   # a space keeps the column width
        else:
            print('*', end=' ')
    print()

فرمول SIZE - 1 - i تعداد فاصله‌های هر سطر را می‌دهد. سطر صفر چهار فاصله دارد، سطر آخر هیچ. اگر این فرمول را نمی‌فهمید، روی کاغذ یک جدول پنج سطری بکشید و برای هر سطر تعداد فاصله و ستاره را بنویسید. کل هنر مسائل الگو همین است.

۷. هرم

# A centred pyramid: row i has (SIZE - 1 - i) leading spaces
# and (2 * i + 1) stars.
SIZE = 5

for i in range(SIZE):
    for space in range(SIZE - 1 - i):
        print(' ', end='')
    for star in range(2 * i + 1):
        print('*', end='')
    print()

print('---')

# The same pyramid in one line per row, using string repetition.
for i in range(SIZE):
    print(' ' * (SIZE - 1 - i) + '*' * (2 * i + 1))

شرح مثال

  • در هر سطر دو حلقه داخلی پشت سر هم داریم: یکی برای فاصله‌ها و یکی برای ستاره‌ها. این کاملاً مجاز است.
  • تعداد ستاره‌ها 2 * i + 1 است، یعنی همیشه فرد: ۱ و ۳ و ۵ و ۷ و ۹. برای همین هرم قرینه در می‌آید.
  • نسخه دوم همان شکل را با تکرار رشته می‌سازد: ' ' * n یعنی n فاصله. یک خط به جای چهار خط، و کاملاً خواناتر. این نمونه خوبی است از اینکه دانستن ابزار درست، کد را کوتاه می‌کند.

۸. مثلث عددی

# Instead of a star we can print the value of the inner counter.
SIZE = 6

for i in range(1, SIZE + 1):
    for j in range(1, i + 1):
        print(j, end=' ')
    print()

print('---')

# And here the row number is repeated instead.
for i in range(1, SIZE + 1):
    for j in range(1, i + 1):
        print(i, end=' ')
    print()

۹. صفحه شطرنج

# The character depends on both counters: when (row + column) is even we print
# one character, otherwise the other one.
SIZE = 8

for row in range(SIZE):
    for column in range(SIZE):
        if (row + column) % 2 == 0:
            print('#', end=' ')
        else:
            print('.', end=' ')
    print()

۱۰. قانون کلی حل مسائل الگو

هر مسئله الگو، هر قدر هم پیچیده به نظر برسد، با همین چهار قدم حل می‌شود:

  1. روی کاغذ بکشیدش. پیش از کد زدن، شکل نهایی را با دست رسم کنید.
  2. سطرها را بشمارید. این عدد، حلقه بیرونی شماست.
  3. برای هر سطر بپرسید چند فاصله و چند نویسه لازم است. یک جدول کوچک بسازید: شماره سطر، تعداد فاصله، تعداد ستاره.
  4. رابطه آن ستون‌ها با شماره سطر را پیدا کنید. این رابطه، همان چیزی است که داخل range حلقه داخلی می‌نویسید.

تمرین‌های فصل هفت

  1. مربعی از ستاره به ابعاد n در n رسم کنید که n را کاربر می‌دهد.
  2. مثلثی رسم کنید که اول بزرگ شود و بعد کوچک، یعنی یک لوزی.
  3. مربع توخالی رسم کنید: فقط لبه‌ها ستاره باشند و داخلش خالی.
  4. جدول ضرب ۱ تا ۱۰ را با یک سطر عنوان در بالا چاپ کنید.
  5. همه زوج‌های (i, j) را چاپ کنید که در آنها 1 <= i < j <= 5.
  6. عدد n را بگیرید و همه جفت‌های عددی کوچک‌تر از n که مجموعشان n می‌شود را چاپ کنید.
  7. مثلثی از حروف بسازید: سطر اول A، سطر دوم A B، سطر سوم A B C و همین‌طور ادامه.
